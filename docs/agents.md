# Agents Overview

Loom Multiverse is powered by 6 specialized agents coordinated by the Orchestrator.

1. **Idea Check Agent:** Validates market viability.
2. **Planning Agent:** Creates technical specs.
3. **Design Agent:** Generates UI/UX components.
4. **Build Agent:** Writes and executes code in E2B sandboxes.
5. **Testing Agent (QA):** Reviews code.
6. **Launch Agent:** Deploys the final product.
