**Table: `Products`** - Stores information about products.
- `product_id` (SERIAL PRIMARY KEY): Unique identifier for each product.
- `supplier_id` (INTEGER REFERENCES Suppliers(supplier_id)): Foreign key linking to the supplier table.
- `name` (VARCHAR(255) NOT NULL): Name of the product.
- `price` (NUMERIC(10, 2)): Price of the product.

**Table: `Orders`** - Stores information about orders.
- `order_id` (SERIAL PRIMARY KEY): Unique identifier for each order.
- `product_id` (INTEGER REFERENCES Products(product_id)): Foreign key linking to the products table.
- `quantity` (INTEGER): Quantity of the product ordered.
- `status` (VARCHAR(50)): Status of the order (e.g., Pending, Shipped, Delivered).

### API Endpoints

- **GET** `/orders`: Retrieves a list of orders.
